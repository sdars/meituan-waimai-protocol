## 2. 通用请求头 / 签名

所有请求在发出前经 `@mtfe/weapp-safety-request` → `jsguard.signWithSiua(options)` 注入:

- `header.mtgsig` : JSON 字符串 (见 `算法原理.md`)
- 业务公共头 (`api/index.js`):
  - `R2X-Referer` = `https://servicewechat.com/wx2c348cf579062e56/0/page-frame.html`
  - `content-type` = `application/x-www-form-urlencoded`
  - `x-env` / `swimlane` (非线上环境)
  - `uuid` = 设备 UUID

请求体 (`reducers/selectors/common-param.js`) 在业务参数基础上合并公共参数:
`wm_ctype=wxapp, wm_dtype, wm_dversion, wm_dplatform, wm_uuid, wm_longitude, wm_latitude,
wm_visitid, wm_appversion, wm_logintoken, userToken, req_time, userid, user_id, ...`。
清洗规则: 值为 object 先 `JSON.stringify`; 值为 falsy (除 `"0"`) 删除。

## 3. 登录链路 (open.meituan.com)

| 步骤 | 方法 | Path | 请求 | 返回 |
|---|---|---|---|---|
| getWxIds | POST(form) | `/user/thirdinfo/getweappuserinfo` | `{code, appName}` | `{openId, openIdCipher, unionId}` |
| silentLogin | POST(form) | `/user/v1/weappsilentlogin` | `{wechatFingerprint, code[, token]}` | `{token, userId, openId, openIdCipher, unionId, data}` |
| newwxSilentLogin | POST(form) | `/user/v1/weappsilentloginembedded` | 同上 | 同上 (netCheck 分支) |
| getMtInfo | GET | `/user/v1/info?token=&fields=` | - | `{user:{id,username,avatarurl,...}}` |

其它登录相关 path (`account-core`):

| key | path |
|---|---|
| getwxuserinfo | `/user/thirdinfo/getwechatuserinfo` |
| updatemtuserinfo | `/user/settings` |
| wxmobilesilentlogin | `/user/v2/weappgetmobilelogin` |
| wxbindapply | `/user/v2/weappbindmobileloginapply` |
| wxbind | `/user/v2/weappbindmobilelogin` |
| newwxsilentlogin | `/user/v1/weappsilentloginembedded` |
| logout | `/thirdlogin/wechatapplogout` |
| generateticket | `/thirdlogin/user/h5/sharelogin/generateTicket` |
| convertTokenToTicket | passport: `/api/account/auth/h5/ticket` |
| ticketlogin | passport: `/api/v1/account/ticketlogin` |

请求包装 (`z()`):
- URL 追加 query: `sdkVersion, utm_medium, joinkey, sdkType=wxmp, login_sdk_version,
  appName, risk_app, risk_partner, risk_platform, risk_smsPrefixId, risk_smsTemplateId,
  version_name, token_id, uuid` (空值不追加)。
- body 合并 `device_type`(=设备 model)、`device_os="微信小程序"`。
- 表单 content-type = `application/x-www-form-urlencoded`。

> **唯一外部输入**: `wx.login` 得到的 `code` (需真实微信环境)。
> 纯协议下可用 YYB 会话铸码 (见 [`登录链路与风控.md`](登录链路与风控.md))。
> `silentLogin` 受美团行为风控限制: 成功返回 `{data:{userId, token}}`,
> 被拦返回 `error.code=101144 (user_has_risk)` 或 HTTP 403 (openresty WAF)。
> `wechatFingerprint` 由 `finger.g()` 纯 Python 生成, 无需设备。

## 4. 业务接口 (wx.waimai.meituan.com/weapp/*)

`API_URL` 全量见 `src/meituan_waimai/api.py` (登录/首页/门店/搜索/购物车/下单/订单/支付/地址/优惠券/活动 等)。

主要分组:

| 分组 | 代表 path |
|---|---|
| 账号 | `/weapp/v1/account/login`, `/weapp/v1/account/getmyaccount`, `/weapp/v2/account/logout` |
| 首页 | `/weapp/v1/v8/home/head`, `/weapp/v9/home/rcmdboard`, `/weapp/v10/home/rcmdboard` |

| 购物车/下单 | `/weapp/weapp/v6/shoppingcart/calculatePrice`, `/weapp/v1/order/preview`, `/weapp/v1/order/submit` |
| 订单 | `/weapp/v1/order/getuserorders`, `/weapp/v3/order/status`, `/weapp/v1/order/detail` |
