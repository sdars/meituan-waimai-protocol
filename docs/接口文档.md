## 2. 通用请求头 / 签名

所有请求在发出前经 `@mtfe/weapp-safety-request` → `jsguard.signWithSiua(options)` 注入:

- `header.mtgsig` : JSON 字符串 (见 `算法原理.md`)
- 业务公共头 (`api/index.js`):
  - `R2X-Referer` = `https://servicewechat.com/wx2c348cf579062e56/0/page-frame.html`
  - `content-type` = `application/x-www-form-urlencoded`
  - `x-env` / `swimlane` (非线上环境)
  - `uuid` = 设备 UUID

请求体 (`reducers/selectors/common-param.js`) 在业务参数基础上合并公共参数:
`wm_ctype=wxapp, wm_dtype, wm_dversion, wm_dplatform, wm_uuid, wm_longitude, wm_latitude,
wm_visitid, wm_appversion, wm_logintoken, userToken, req_time, userid, user_id, ...`。
清洗规则: 值为 object 先 `JSON.stringify`; 值为 falsy (除 `"0"`) 删除。

## 5. 双域实测 + 边缘 WAF 触发条件 (2026-10-11)

同一份签名 (mtgsig) + 同一份登录态, 分别打 prod 与 st 域全量 88 路径:

| 域 | 403 数 / 总 | 说明 |
|---|---|---|
| `wx.waimai.meituan.com` (prod) | **31 / 88** | 边缘 WAF 路径级拦截 |
| `wx.waimai.st.meituan.com` (st) | **0 / 88** | 全放行 |

prod 域 403 路径集合 (openresty, 响应头 `X-Forbid-Reason: .`, body 为默认
`<center><h1>403 Forbidden</h1>` HTML, 非业务 JSON):

```
productDetail getFoodMultiSpu getMultiSkuPrice poiCommentInfo searchPoi
searchPoiWithFilter searchSuggestV8 searchHot innerShopHotProducts
innerShopSearchProducts calculatePrice v8OrderPreview orderCollection orders

```

### 5.1 403 与签名/UA/safety 参数无关 (排除实验)

对上述 403 路径逐一做了以下改动, **仍然 403**:

1. 补默认 `User-Agent` (微信小程序 UA) → 403 不变;
2. 补 `@mtfe/weapp-safety-request` 的 url 注入 (`yodaReady/csecappid/csecplatform/
   csecversionname/csecversion`) + header 注入 (`token/csecuuid/csecuserid/
   openId/openIdCipher`) → 403 不变;
3. 完全裸请求 (无 mtgsig, 仅带正常 UA) → 仍 403 (`X-Forbid-Reason: .`);
4. 同一路径打 **st 域** → 200 (返回业务 JSON, 如 `getCouponsList` 返回
   `{"code":1,"msg":"当前访问人数较多..."}`, 说明接口存在、签名有效)。

**结论**: prod 域 403 是 **出口 IP 级边缘 WAF 路径黑名单** (本机出口在美国 LA,
`104.250.109.150` AS64245 DigitalFyre)。这是**环境问题, 非协议问题**——st 域用
完全相同的签名/参数即全量放行, 证明协议闭合链路正确。与美团返返
(`offsiteact.meituan.com`) 的 403 模式**完全一致**。

## 6. safety-request 层注入 (api.py 已复现)

`api/urls.js` 请求经 `@mtfe/weapp-safety-request3.0.1` 的 `addCommonParams`
(`constants/common.js` `PARAMS_POS`) 注入, 与 fanfan 同款:

- **url query** (`PARAMS_POS.url`): `yodaReady, csecappid, csecplatform,
  csecversionname, csecversion`
- **header** (`PARAMS_POS.header`): `token, csecuuid, csecdpid, csecuserid,
  openId, openIdCipher, eptoken, csecepuid`
- `defaultInitParams = {csecversion: "3.0.0"(SDK VERSION)} + envParams{yodaReady:"wx",
  csecplatform:3}`; `csecappid/csecversionname` 来自 `app.js` 的 `params()`
  (`csecappid="wx2c348cf579062e56"`, `csecversionname=小程序版本`)。

`WaimaiClient.request(..., apply_safety=True)` 默认执行该注入。
