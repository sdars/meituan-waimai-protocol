# 美团外卖小程序 签名算法原理

> 来源: 小程序内置 `utils/jsguard.js` (jsguard **2.5.0**)。
> 全部为纯 Python 静态复现, 无动态转发。验证代码见 `tests/test_protocol.py`。

## 1. mtgsig (ee / signWithSiua)

请求 header `mtgsig` 是一个 JSON 字符串:

| 字段 | 含义 |
|---|---|
| a1 | 协议版本 `"1.2"` |
| a2 | 毫秒时间戳 `Date.now() + serverTimeDiff` |
| a3 | dfpId (`finger.d()`) |
| a4 | 48 hex 摘要 |
| a5 | 主密文 (自定义 base64) |
| a6 | siua 指纹串 (`finger.i()`) |
| a7 | appId `wx2c348cf579062e56` |
| x0 | `3` |
| d1 | md5 混淆摘要 |

### 1.1 待签名串 w

`w = enc(method + " " + path + " " + sorted_query)` 再拼接 body:

- query 解析后按 `(key, value)` 排序 (先 key 后 value), 每对 `enc(k)=enc(v)` 用 `&` 连接。
- GET: 把 data 对象展开为 query 对。
- 表单 (`x-www-form-urlencoded`): body = `enc(k)=enc(v)` 连接。
- 其它: body = `JSON.stringify(data)`。

实现: `signer.build_w()`。

### 1.2 a4 / a5

```
l = K(i)                        # i 的 4 字节大端
g = W(siua) + l
v = md5_hex(g)
m = H(v[:15])                   # 前 15 hex -> 15 字节
m[7] = (env_flag ^ crc32(l)) & 255
m += l
m += K(crc32(m))
a5 = x_b64(m + cb(m, pc_json))  # 自定义 base64
S = murmur2(w, i)
A = murmur2(W(a5), i)
I = md5ToHex([S, A, S^i, S^A^i])
D = b2h(K(S) + K(A) + I)        # a4
```

`pc_json` = `Pc` 对象 JSON (键序 `b7,b1,b8,b12,b2,b9`):

- `b7` = 秒级时间戳
- `b1` = 账号信息 `{miniProgram:{appId,envVersion,version}}`
- `b8` = 请求序号 (自增)
- `b12` = appId
- `b2` = 页面路由 (默认 `""`)
- `b9` = `"00102"`

### 1.3 d1

```
T = a1 + str(i) + a3 + a4 + str(A) + v + a7
j = md5Array(W(T))
N = rol(i, x0)
j0 ^= N; j1 ^= A; j2 ^= A ^ N; j3 ^= j0
d1 = md5ToHex(j)
```

### 1.4 关键坑

- **CRC32 常量**: jsguard 源码里多项式写的是**十进制 `3988292384`** (= 0xEDB88320),
  最终异或常量是**十进制 `306674911`** (= 0x12477CDF)。
- `md5ToHex`: 每个 32 位字按字节小端拆 4 字节, 每字节**低半字节在前**。
- `env_flag` = **123** (真实小程序环境; fanfan 为 6)。

实现: `_mtgsig.sign()`。

## 2. 自定义 VM (cb / rc4)

a5 密文 = `m + cb(m, pc_json)`。`cb` 是一段 jsguard 自实现的 RC4 变体:

```
# KSA
s = list(range(256)); o = 0
for i in range(256):
    o = (o + s[i] + m[i % len(m)] + 31) % 256
    swap(s[i], s[o])
# PRGA
i = 0; o = 0
for b in pc_bytes:
    o = (o + 1) % 256
    i = (i + s[o]) % 256
    swap(s[o], s[i])
    out.append(b ^ s[(s[o] + s[i]) % 256])
```

实现: `_vm.cb()` / `_vm.rc4_prga()`。

## 3. 设备指纹

- `finger.i()` (siua, mtgsig.a6): `'w1.6' + base64(AES-128-CBC(gzip(JSON(DFP 数组))))`。
  AES key/iv 与 fanfan 一致: key `z7Jut6Ywr2Pe5Nhx`, iv `0807060504030201`。
- `finger.d()` (dfpId, mtgsig.a3): siua 去掉 4 字符前缀后的主体。
- `Sn()` localId: `ts + randAZ7 + md5(json) + crc32十进制前4位`。
- `finger.g()` (wechatFingerprint): 前缀 `WX__ver1.2.0_CCCC_` + `base64(AES-CBC(gzip(json)))`,
  序列化前删除 `fsmode/e/ext/dp/sessionId` 及 system 的若干运行时字段。

DFP 序列化键序 (`yt.DFP`): `app, dfpid, filetime, fpv, localid, system, timestamp, ext, sessionId`。
`system` 为 43 项固定 schema (见 `_finger.SYSTEM_FIELDS`)。

实现: `_finger.build_dfp_array()` / `build_siua()` / `build_wechat_fingerprint()`。
